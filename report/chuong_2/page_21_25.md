## 2.5. Foundational Theory

### 2.5.1. Automatic Speech Recognition (ASR)

### 2.5.1.1. ASR concept and operating principle
Automatic Speech Recognition (ASR) is the technology that converts human speech audio into corresponding text. Traditional ASR processing includes acoustic feature extraction (for example MFCCs), acoustic modeling, language modeling, and decoding.

In recent years, end-to-end deep learning architectures such as Connectionist Temporal Classification (CTC), Recurrent Neural Network Transducer (RNN-T), and Transformer-based encoder-decoder models (such as OpenAI Whisper or Qwen ASR) have become dominant because they can learn the mapping directly from spectrograms to character sequences without complex intermediate steps.

### 2.5.1.2. Qwen ASR and Qwen3ASRModel
In VocalMind, the team chose **Qwen ASR** through the `qwen-asr` library (`Qwen3ASRModel`). Qwen ASR is a powerful multilingual speech recognition model developed by Alibaba Group and trained on tens of thousands of hours of diverse audio data.
*   **Architecture:** It uses an advanced Transformer-based Audio Encoder to extract semantic representations of audio, combined with a Language Decoder to generate text.
*   **Key characteristics:** Qwen ASR provides excellent Vietnamese and English recognition, strong noise suppression, and good handling of abbreviations and IT terminology. Using `Qwen3ASRModel.from_pretrained()` allows the system to load pre-trained weights and run inference directly on CUDA-capable hardware for maximum speed.

### 2.5.2. Text-to-Speech (TTS)

### 2.5.2.1. Concept and modern TTS architecture
Text-to-Speech (TTS) is the process of converting text into synthetic speech audio that sounds human-like. Modern TTS systems are usually divided into two main stages:
1.  **Front-end model (text-to-spectrogram):** Parses the input text, converts written words into phonemes, and produces an intermediate Mel-spectrogram representation. Common architectures include Tacotron 2 and FastSpeech 2.
2.  **Vocoder model (spectrogram-to-waveform):** Converts the intermediate Mel-spectrogram into a raw digital waveform (.wav). Well-known deep-learning vocoders include WaveGlow and HiFi-GAN.

### 2.5.2.2. Vieneu TTS for Vietnamese
VocalMind integrates the **Vieneu** library (`vieneu` and `BaseVieneuTTS`), a high-quality TTS solution specialized for Vietnamese.
*   **Key advantage:** Unlike other free Vietnamese speech synthesis libraries that often sound flat and robotic, Vieneu uses advanced deep neural network architecture to accurately model intonation, Vietnamese tone marks (grave, acute, hook, tilde, dot), and natural pauses based on semantic phrasing.
*   **Emotion and preset voice support:** The library allows voice emotion control (for example happy, serious, gentle) through the `emotion` parameter and different voice presets (male/female, northern/southern accents) through `get_preset_voice(voice)`. This supports varied assistant personalities based on user preference.

### 2.5.3. Mem0 intelligent memory system (Memory Layer)

### 2.5.3.1. Concept of Personal AI Memory
In ordinary AI chat applications, conversation context is passed by sending the entire chat history together with the new question on each API call. This has two critical drawbacks:
1.  **Context window limit:** As the conversation grows, the token count exceeds the LLM's allowed limit.
2.  **High compute cost and poor long-term recall:** Resending the entire history increases API cost, and the model quickly forgets important details mentioned days or weeks earlier.

Personal AI memory solves this by working independently of the LLM context window. It proactively extracts important knowledge, stores it in vector and knowledge-graph databases, and retrieves only the knowledge relevant to the current question for context (RAG - Retrieval-Augmented Generation).

### 2.5.3.2. Mem0 memory engine (`mem0ai`)
VocalMind uses the **Mem0** library (included through the `mem0ai` package). Mem0 is an intelligent memory management framework for AI agents with the following characteristics:
*   **Multi-tier memory:** Supports User Memory for habits and preferences, Session Memory for short-term conversation context, and Organization Memory for shared knowledge.
*   **Memory graph:** Instead of storing only flat text snippets, Mem0 organizes memories as an entity-relationship graph. When a user says, "I have a meeting with Minh on Thursday," Mem0 automatically links the entity "I" to "Minh" through the relationship "meeting" with the time attribute "Thursday."
*   **Continuous learning:** Mem0 automatically updates memory when new or conflicting information appears. For example, if the user first says "Minh owes me 60k" and later says "Minh paid me 40k," Mem0 can automatically compute or update Minh's debt without manual code.
*   **Vector database integration:** Mem0 supports vector databases such as Qdrant, Chroma, or internal tools to perform accurate semantic search over memories.
