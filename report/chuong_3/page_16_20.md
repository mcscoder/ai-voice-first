## 3.4. Chi tiết công nghệ sử dụng và triển khai mã nguồn Backend

### 3.4.1. Cấu hình API endpoints bằng FastAPI (`backend/app/api/routes.py`)
Hệ thống Backend của **VocalMind** được xây dựng bằng Python và framework **FastAPI**, tận dụng khả năng xử lý không đồng bộ (`async`/`await`) để phục vụ các yêu cầu API đồng thời với hiệu năng tối ưu nhất. 

Endpoint cốt lõi nhất là `/v1/voice/assistant` xử lý luồng tích hợp giọng nói. Mã nguồn triển khai phương thức này như sau:

```python
@router.post(
    "/v1/voice/assistant",
    responses={
        200: {
            "content": {
                "audio/wav": {
                    "schema": {"type": "string", "format": "binary"},
                },
            },
            "description": "Generated assistant WAV audio",
        },
    },
    response_class=Response,
)
async def voice_assistant(
    file: UploadFile = File(...),
    language: str | None = Form(None),
) -> Response:
    # 1. Đọc tệp tin âm thanh tải lên từ Client dưới dạng bytes nhị phân
    audio_bytes = await file.read()
    if not audio_bytes:
        raise HTTPException(status_code=400, detail="Uploaded file is empty.")

    # 2. Thực thi xử lý AI (ASR -> Memory/LLM -> TTS) trong luồng phụ (thread pool)
    # để tránh làm nghẽn luồng sự kiện chính (event loop) của FastAPI
    result = await asyncio.to_thread(
        assistant_service.respond,
        audio_bytes,
        language,
    )

    # 3. Trả về âm thanh phản hồi dạng WAV nhị phân cho Client phát lại
    return Response(
        content=result.audio,
        media_type=result.media_type,
        headers={"Content-Disposition": 'attachment; filename="assistant.wav"'},
    )
```

### 3.4.2. Điều phối dịch vụ Trợ lý thông minh (`backend/app/services/assistant/service.py`)
Lớp `AssistantService` đóng vai trò nhạc trưởng điều phối dữ liệu đi qua 3 dịch vụ con: `AsrService`, `MemoryService` và `TtsService`. Quy trình được thực hiện tuần tự và trả về đối tượng kết quả chứa mảng bytes âm thanh cuối cùng:

```python
class AssistantService:
    """Coordinates voice assistant ASR, memory, and TTS services."""

    def __init__(
        self,
        asr: AsrService = asr_service,
        memory: MemoryService = memory_service,
        tts: TtsService = tts_service,
        user_id: str = DEFAULT_USER_ID,
    ) -> None:
        self.asr = asr
        self.memory = memory
        self.tts = tts
        self.user_id = user_id

    def respond(
        self,
        audio: bytes | AudioLike,
        language: str | None = None,
    ) -> AssistantResult:
        // Bước 1: Gọi dịch vụ ASR để nhận dạng giọng nói thành văn bản
        transcription = self.asr.transcribe(audio, language)
        
        // Bước 2: Truy xuất bộ nhớ ngữ cảnh và sinh câu trả lời bằng LLM qua Mem0
        assistant_reply = self.memory.respond(transcription.text, self.user_id)
        
        // Bước 3: Tổng hợp câu trả lời dạng chữ thành âm thanh qua Vieneu TTS
        speech = self.tts.synthesize(assistant_reply.text, None)

        return AssistantResult(
            audio=speech.audio,
            media_type=speech.media_type,
        )
```

### 3.4.3. Xử lý âm thanh đa phương tiện và Mô hình ASR (`backend/app/services/asr/service.py`)
Một thách thức lớn khi xây dựng hệ thống giọng nói là giải mã (decode) các định dạng âm thanh đa dạng gửi từ thiết bị di động (như AAC, M4A, OPUS). `AsrService` giải quyết vấn đề này bằng cách tích hợp thư viện **PyAV** (`av`) để giải mã âm thanh nhị phân trực tiếp trên bộ nhớ thành mảng NumPy kiểu số thực 32-bit (`float32`), chuẩn hóa tần số lấy mẫu trước khi nạp vào mô hình **Qwen ASR**:

```python
def decode_audio_bytes(self, audio_bytes: bytes) -> AudioLike:
    audio_chunks: list[np.ndarray] = []
    sample_rate: int | None = None

    # Sử dụng PyAV để mở luồng âm thanh từ bộ nhớ bytes
    with av.open(BytesIO(audio_bytes), mode="r") as container:
        # Giải mã các khung dữ liệu âm thanh (audio frames)
        for frame in container.decode(audio=0):
            sample_rate = int(frame.sample_rate)
            chunk = frame.to_ndarray()
            # Chuẩn hóa âm thanh về khoảng [-1.0, 1.0]
            audio_chunks.append(self._normalize_audio_chunk(chunk))

    if not audio_chunks or sample_rate is None:
        raise AsrError("Uploaded audio contains no decodable audio frames.")

    # Ghép nối các đoạn âm thanh và chuyển đổi định dạng mono/stereo
    audio = np.concatenate(audio_chunks, axis=0)
    if audio.shape[1] == 1:
        audio = audio[:, 0]

    return np.asarray(audio, dtype=np.float32), int(sample_rate)
```

### 3.4.4. Tích hợp Mô hình Ký ức và LLM bằng Mem0 (`backend/app/services/memory/service.py`)
`MemoryService` chịu trách nhiệm quản lý bộ nhớ thông qua framework **Mem0**. Cấu hình backend hiện sử dụng provider `deepseek` với mô hình `deepseek-v4-flash` tại endpoint `https://api.deepseek.com`; khóa truy cập được cung cấp qua biến môi trường `DEEPSEEK_API_KEY`. Khi nhận được văn bản câu nói của người dùng, dịch vụ thực hiện truy vấn các ký ức liên quan, xây dựng prompt ngữ cảnh và đưa vào mô hình ngôn ngữ lớn để tạo phản hồi:

```python
def respond(self, text: str, user_id: str = DEFAULT_USER_ID) -> MemoryReply:
    query = text.strip()
    if not query:
        raise MemoryServiceError("Memory service received empty text.")

    memory = self.load_memory()
    # 1. Tìm kiếm các ký ức tương đồng ngữ nghĩa trong Vector DB của Mem0
    memories = self._search_memories(memory, query, user_id)
    
    # 2. Sinh câu trả lời thông qua DeepSeek LLM có kèm tri thức ngữ cảnh
    response_text = self._generate_response(memory, query, memories)

    # 3. Ghi nhận thông tin hội thoại mới vào bộ nhớ dài hạn
    memory.add(
        [
            {"role": "user", "content": query},
            {"role": "assistant", "content": response_text},
        ],
        user_id=user_id,
    )

    return MemoryReply(text=response_text, user_id=user_id)
```

### 3.4.5. Tổng hợp giọng nói Vieneu TTS (`backend/app/services/tts/service.py`)
`TtsService` sử dụng mô hình **Vieneu** để thực hiện tổng hợp giọng nói tiếng Việt chuẩn. Lớp này tải mô hình lên GPU (nếu có CUDA) và thực hiện sinh âm thanh WAV nhị phân:

```python
def synthesize(self, text: str, voice: TtsVoice | None = None) -> TtsResult:
    with self._lock:
        # Tải mô hình Vieneu
        model = self._model or self.load_model()
        # Lấy preset giọng đọc được cấu hình (ví dụ: giọng nữ miền Nam, giọng nam miền Bắc)
        voice_data = model.get_preset_voice(voice or self.default_voice)
        # Thực hiện suy luận sinh tín hiệu âm thanh thô
        audio = model.infer(text=text, voice=voice_data, emotion=self.emotion)
        # Mã hóa mảng NumPy âm thanh sang định dạng file WAV nhị phân tiêu chuẩn
        audio_bytes = self.encode_audio(audio)

    if not audio_bytes:
        raise EmptyTtsAudioError("TTS synthesis returned no audio.")

    return TtsResult(
        audio=audio_bytes,
        media_type="audio/wav",
    )
```
