## 3.4. Technology Details and Backend Source Code Implementation

### 3.4.1. API endpoint configuration with FastAPI (`backend/app/api/routes.py`)
The **VocalMind** backend is built with Python and the **FastAPI** framework, using asynchronous processing (`async`/`await`) to serve API requests concurrently with optimal performance.

The core endpoint is `/v1/voice/assistant`, which handles the integrated voice flow. The implementation is as follows:

```python
@router.post(
    "/v1/voice/assistant",
    responses={
        200: {
            "content": {
                "audio/wav": {
                    "schema": {"type": "string", "format": "binary"},
                },
            },
            "description": "Generated assistant WAV audio",
        },
    },
    response_class=Response,
)
async def voice_assistant(
    file: UploadFile = File(...),
    language: str | None = Form(None),
) -> Response:
    # 1. Read the uploaded audio file from the Client as binary bytes
    audio_bytes = await file.read()
    if not audio_bytes:
        raise HTTPException(status_code=400, detail="Uploaded file is empty.")

    # 2. Run AI processing (ASR -> Memory/LLM -> TTS) in a worker thread
    # to avoid blocking FastAPI's main event loop
    result = await asyncio.to_thread(
        assistant_service.respond,
        audio_bytes,
        language,
    )

    # 3. Return binary WAV response audio for Client playback
    return Response(
        content=result.audio,
        media_type=result.media_type,
        headers={"Content-Disposition": 'attachment; filename="assistant.wav"'},
    )
```

### 3.4.2. Intelligent assistant service orchestration (`backend/app/services/assistant/service.py`)
The `AssistantService` class acts as the conductor coordinating data across three sub-services: `AsrService`, `MemoryService`, and `TtsService`. The flow is sequential and returns a result object containing the final audio byte array:

```python
class AssistantService:
    """Coordinates voice assistant ASR, memory, and TTS services."""

    def __init__(
        self,
        asr: AsrService = asr_service,
        memory: MemoryService = memory_service,
        tts: TtsService = tts_service,
        user_id: str = DEFAULT_USER_ID,
    ) -> None:
        self.asr = asr
        self.memory = memory
        self.tts = tts
        self.user_id = user_id

    def respond(
        self,
        audio: bytes | AudioLike,
        language: str | None = None,
    ) -> AssistantResult:
        // Step 1: Call the ASR service to convert speech to text
        transcription = self.asr.transcribe(audio, language)
        
        // Step 2: Retrieve contextual memory and generate an answer through Mem0 + LLM
        assistant_reply = self.memory.respond(transcription.text, self.user_id)
        
        // Step 3: Synthesize the text answer into audio through Vieneu TTS
        speech = self.tts.synthesize(assistant_reply.text, None)

        return AssistantResult(
            audio=speech.audio,
            media_type=speech.media_type,
        )
```

### 3.4.3. Multimedia audio processing and the ASR model (`backend/app/services/asr/service.py`)
A major challenge in building a voice system is decoding the many audio formats sent from mobile devices, such as AAC, M4A, and OPUS. `AsrService` solves this by integrating **PyAV** (`av`) to decode binary audio directly in memory into 32-bit float NumPy arrays (`float32`) and normalize the sample rate before passing it to **Qwen ASR**:

```python
def decode_audio_bytes(self, audio_bytes: bytes) -> AudioLike:
    audio_chunks: list[np.ndarray] = []
    sample_rate: int | None = None

    # Use PyAV to open the audio stream from memory bytes
    with av.open(BytesIO(audio_bytes), mode="r") as container:
        # Decode audio frames
        for frame in container.decode(audio=0):
            sample_rate = int(frame.sample_rate)
            chunk = frame.to_ndarray()
            # Normalize audio to the range [-1.0, 1.0]
            audio_chunks.append(self._normalize_audio_chunk(chunk))

    if not audio_chunks or sample_rate is None:
        raise AsrError("Uploaded audio contains no decodable audio frames.")

    # Concatenate audio chunks and convert mono/stereo format
    audio = np.concatenate(audio_chunks, axis=0)
    if audio.shape[1] == 1:
        audio = audio[:, 0]

    return np.asarray(audio, dtype=np.float32), int(sample_rate)
```

### 3.4.4. Integrating memory and LLM through Mem0 (`backend/app/services/memory/service.py`)
`MemoryService` handles memory management through the **Mem0** framework. The backend currently uses the `deepseek` provider with the `deepseek-v4-flash` model at `https://api.deepseek.com`; the access key is provided via the `DEEPSEEK_API_KEY` environment variable. When it receives the user's speech text, the service searches related memories, builds a contextual prompt, and sends it to the LLM to generate a response:

```python
def respond(self, text: str, user_id: str = DEFAULT_USER_ID) -> MemoryReply:
    query = text.strip()
    if not query:
        raise MemoryServiceError("Memory service received empty text.")

    memory = self.load_memory()
    # 1. Search for semantically similar memories in Mem0's vector DB
    memories = self._search_memories(memory, query, user_id)
    
    # 2. Generate an answer through DeepSeek LLM with contextual knowledge
    response_text = self._generate_response(memory, query, memories)

    # 3. Store the new conversation in long-term memory
    memory.add(
        [
            {"role": "user", "content": query},
            {"role": "assistant", "content": response_text},
        ],
        user_id=user_id,
    )

    return MemoryReply(text=response_text, user_id=user_id)
```

### 3.4.5. Vieneu TTS speech synthesis (`backend/app/services/tts/service.py`)
`TtsService` uses the **Vieneu** model for high-quality Vietnamese speech synthesis. The class loads the model onto the GPU (if CUDA is available) and generates binary WAV audio:

```python
def synthesize(self, text: str, voice: TtsVoice | None = None) -> TtsResult:
    with self._lock:
        # Load the Vieneu model
        model = self._model or self.load_model()
        # Get the configured voice preset (for example, southern female or northern male)
        voice_data = model.get_preset_voice(voice or self.default_voice)
        # Run inference to generate raw audio
        audio = model.infer(text=text, voice=voice_data, emotion=self.emotion)
        # Encode the NumPy audio array into standard binary WAV format
        audio_bytes = self.encode_audio(audio)

    if not audio_bytes:
        raise EmptyTtsAudioError("TTS synthesis returned no audio.")

    return TtsResult(
        audio=audio_bytes,
        media_type="audio/wav",
    )
```
