## 3.5. Chi tiết mã nguồn Frontend và Quản lý trạng thái trong Flutter

### 3.5.1. Quản lý trạng thái với Hydrated BLoC (`app/lib/features/voice/presentation/voice_capture_cubit.dart`)
Ứng dụng di động VocalMind sử dụng mẫu thiết kế **BLoC (Business Logic Component)** thông qua thư viện `flutter_bloc` để tách biệt phần hiển thị giao diện với logic nghiệp vụ. Đặc biệt, lớp `VoiceCaptureCubit` kế thừa từ `HydratedCubit` của thư viện `hydrated_bloc` nhằm tự động lưu trữ cấu hình lựa chọn ngôn ngữ của người dùng xuống bộ nhớ máy (`Hive/SecureStorage`) dưới định dạng JSON. Điều này giúp cấu hình ngôn ngữ của người dùng được khôi phục ngay lập tức khi khởi động lại ứng dụng mà không cần gọi API hay yêu cầu chọn lại.

Mã nguồn điều khiển logic ghi âm và giao tiếp API của `VoiceCaptureCubit` được triển khai như sau:

```dart
@injectable
class VoiceCaptureCubit extends HydratedCubit<VoiceCaptureState> {
  VoiceCaptureCubit(
    this._permissionService,
    this._audioRecorderService,
    this._transcriptionApi, {
    Future<void> Function(Uint8List audioBytes)? playAssistantSpeech,
    Storage? storage,
  }) : super(const VoiceCaptureState(), storage: _resolveStorage(storage)) {
    // Khởi tạo trình phát âm thanh mặc định
    final player = AudioPlayer();
    _audioPlayer = player;
    _playAssistantSpeech = (audioBytes) async {
      // Phát trực tiếp mảng bytes WAV nhận được từ Server dưới dạng luồng âm thanh
      await player.play(BytesSource(audioBytes, mimeType: 'audio/mpeg'));
    };
  }

  final PermissionService _permissionService;
  final AudioRecorderService _audioRecorderService;
  final TranscriptionApi _transcriptionApi;
  late final AudioPlayer? _audioPlayer;
  late final Future<void> Function(Uint8List audioBytes) _playAssistantSpeech;

  // Thay đổi ngôn ngữ giao tiếp chủ đạo
  void selectLanguage(VoiceLanguage language) {
    if (state.isBusy || language.code == state.selectedLanguage.code) return;
    emit(state.copyWith(selectedLanguage: language, clearFailure: true));
  }

  // Phương thức chuyển đổi bắt đầu / dừng ghi âm
  Future<void> toggleRecording() async {
    switch (state.status) {
      case VoiceCaptureStatus.idle:
      case VoiceCaptureStatus.success:
      case VoiceCaptureStatus.failure:
        await startRecording();
        return;
      case VoiceCaptureStatus.recording:
        await stopRecording();
        return;
      case VoiceCaptureStatus.uploading:
      case VoiceCaptureStatus.processing:
      case VoiceCaptureStatus.speaking:
        return; // Khóa tương tác khi hệ thống đang bận xử lý
    }
  }
  
  // Tự động chuyển đổi trạng thái sang JSON để lưu trữ offline
  @override
  VoiceCaptureState? fromJson(Map<String, dynamic> json) {
    return VoiceCaptureState(
      selectedLanguage: VoiceLanguage.fromCode(json['selectedLanguage'] as String?),
    );
  }

  @override
  Map<String, dynamic>? toJson(VoiceCaptureState state) {
    return {'selectedLanguage': state.selectedLanguage.code};
  }
}
```

### 3.5.2. Quy trình kiểm tra và cấp quyền thiết bị (Microphone Permission)
Trước khi khởi động ghi âm, ứng dụng phải đảm bảo quyền truy cập microphone của điện thoại đã được cấp phép. Ứng dụng gọi dịch vụ `PermissionService` để kiểm tra trạng thái quyền:

```dart
Future<void> startRecording() async {
  // 1. Kiểm tra trạng thái cấp quyền microphone của hệ điều hành di động
  final status = await _permissionService.check(AppPermission.microphone);

  if (status == AppPermissionStatus.denied) {
    // 2. Yêu cầu cấp quyền nếu quyền đang ở trạng thái từ chối (Denied)
    final requested = await _permissionService.request(AppPermission.microphone);
    if (!_isGranted(requested)) {
      emit(state.copyWith(
        status: VoiceCaptureStatus.failure,
        failure: requested == AppPermissionStatus.permanentlyDenied
            ? VoiceCaptureFailure.microphonePermanentlyDenied
            : VoiceCaptureFailure.microphoneDenied,
      ));
      return;
    }
  } else if (!_isGranted(status)) {
    emit(state.copyWith(
      status: VoiceCaptureStatus.failure,
      failure: status == AppPermissionStatus.permanentlyDenied
          ? VoiceCaptureFailure.microphonePermanentlyDenied
          : VoiceCaptureFailure.microphoneDenied,
    ));
    return;
  }

  // 3. Khởi chạy thiết bị ghi âm khi quyền đã được cấp thành công
  try {
    await _audioRecorderService.start();
    emit(state.copyWith(
      status: VoiceCaptureStatus.recording,
      reply: '',
      clearFailure: true,
    ));
  } on AudioRecordingException {
    emit(state.copyWith(
      status: VoiceCaptureStatus.failure,
      failure: VoiceCaptureFailure.microphoneDenied,
    ));
  }
}
```

### 3.5.3. Quy trình gửi dữ liệu âm thanh và nhận phản hồi phát lại
Khi người dùng bấm dừng ghi âm, cubit thực thi phương thức `stopRecording()`. Quy trình này bao gồm việc dừng thiết bị ghi âm, lấy đường dẫn tệp tạm thời, gửi tệp qua API Client sử dụng thư viện **Dio** (hỗ trợ theo dõi tiến trình gửi `onSendProgress`), nhận mảng bytes âm thanh phản hồi từ server và kích hoạt trình phát âm thanh `AudioPlayer`:

```dart
Future<void> stopRecording() async {
  // Chuyển trạng thái sang Uploading
  emit(state.copyWith(status: VoiceCaptureStatus.uploading, clearFailure: true));
  String? filePath;

  try {
    // 1. Dừng ghi âm và thu được đường dẫn tệp âm thanh tạm thời (.m4a)
    filePath = await _audioRecorderService.stop();

    // 2. Gửi tệp tin lên Backend và theo dõi tiến trình upload dữ liệu
    final result = await _transcriptionApi.respond(
      filePath: filePath,
      language: state.selectedLanguage,
      onSendProgress: (sent, total) {
        if (total > 0 && sent >= total && state.status == VoiceCaptureStatus.uploading) {
          // Chuyển trạng thái sang Processing khi file đã tải lên trọn vẹn
          emit(state.copyWith(status: VoiceCaptureStatus.processing, clearFailure: true));
        }
      },
    );

    final error = result.error;
    final audio = result.audio;

    if (error != null) {
      emit(state.copyWith(status: VoiceCaptureStatus.failure, failure: _mapNetworkError(error)));
      return;
    }

    final audioBytes = audio ?? Uint8List(0);
    if (audioBytes.isEmpty) {
      emit(state.copyWith(status: VoiceCaptureStatus.failure, failure: VoiceCaptureFailure.badAudio));
      return;
    }

    // 3. Nhận dữ liệu âm thanh phản hồi từ AI Server và chuyển sang trạng thái Speaking
    emit(state.copyWith(status: VoiceCaptureStatus.speaking, clearFailure: true));

    // 4. Phát giọng nói của trợ lý ảo ra loa thiết bị di động
    await _playAssistantSpeech(audioBytes);

    // Chuyển sang trạng thái thành công
    emit(state.copyWith(status: VoiceCaptureStatus.success, clearFailure: true));
  } catch (e) {
    emit(state.copyWith(status: VoiceCaptureStatus.failure, failure: VoiceCaptureFailure.unknown));
  } finally {
    // 5. Giải phóng tài nguyên và xóa tệp ghi âm tạm thời khỏi bộ nhớ thiết bị
    if (filePath != null) {
      await _audioRecorderService.deleteRecording(filePath);
    }
  }
}
```
